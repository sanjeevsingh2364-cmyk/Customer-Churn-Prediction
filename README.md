# Customer Churn Prediction

## Project Overview
This is a Machine Learning project that predicts whether a customer is likely to leave a service.

## Objectives
- Analyze customer data.
- Perform Exploratory Data Analysis (EDA).
- Prepare data for Machine Learning.
- Train and evaluate classification models.

## Dataset
The dataset contains customer information such as Age, Tenure, Usage Frequency, Support Calls, Payment Delay, Total Spend, Subscription Type, Contract Length, and Churn.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Git and GitHub

## Project Workflow
1. Load the dataset.
2. Explore and clean the data.
3. Perform data analysis and visualization.
4. Prepare features and target variables.
5. Train Machine Learning models.
6. Evaluate the models using Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

## Project Files
- `customer_churn_dataset.csv` — Dataset
- `data_exploration.ipynb` — Jupyter Notebook
- `README.md` — Project documentation

## How to Run
Install the required libraries:

`pip install pandas numpy matplotlib seaborn scikit-learn jupyter`

Open `data_exploration.ipynb` in Jupyter Notebook and run the cells in order.
